# ¿Por qué decidí estudiar ASIR?

## Mi motivación

Desde pequeño siempre me **fascinaron los ordenadores** y cómo funcionan las redes por dentro. Para mí, la informática es *una vocación*, no solo un trabajo.

> "La tecnología es mejor cuando une a las personas." — Matt Mullenweg

## Mis razones principales

- Salida laboral muy buena
- Me gusta resolver problemas
- Quiero trabajar con servidores y redes

## Lo que quiero aprender

1. Administración de sistemas Linux y Windows
2. Redes y seguridad
3. Bases de datos

## Mi primer comando favorito

```bash
sudo apt update && sudo apt upgrade
```

También uso el comando `ping` para comprobar la conectividad.
